## Roles & Responsibilities

Design, develop, and deploy Generative AI and LLM-based applications for real-world business use cases.
Build and optimize RAG (Retrieval-Augmented Generation) pipelines using enterprise and unstructured data.
Develop GenAI solutions using Python, LangChain, LlamaIndex, or similar frameworks.
Integrate and work with LLMs such as OpenAI, Azure OpenAI, AWS Bedrock, Gemini, or equivalent models.
Implement prompt engineering, embeddings, semantic search, and vector database solutions.
Develop document-processing workflows including data ingestion, chunking, retrieval, and knowledge extraction.
Build REST APIs and AI services using FastAPI, Flask, or similar technologies.
Develop AI Agents / Agentic AI workflows to automate complex business processes.
Evaluate and improve LLM applications for accuracy, relevance, hallucination, latency, and cost.
Collaborate with software engineers, data scientists, architects, and business teams to deliver scalable AI solutions.
Deploy and maintain GenAI applications on AWS, Azure, or GCP environments.
Participate in solution design, code reviews, testing, troubleshooting, and production support.
